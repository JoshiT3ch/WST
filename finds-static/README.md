# Finds — website frontend

## Open the website

From the project root (one folder above this one), run `npm install` and `npm start`, then open [http://localhost:3000](http://localhost:3000). The Node.js server provides the product and contact APIs. Opening the HTML files directly or through Live Server does not provide these APIs. See the [project README](../README.md) for configuration and API details.

## What works

- Five linked pages with the same navigation and footer.
- Shared Finds search header, category menus that open on desktop hover, mobile category toggle, keyboard focus indicators, and skip link.
- API-backed listing search with Woman/Men/Kids filtering, loading, error, retry, and empty-results states. The menus browse the current four-item sample collection.
- Temporary favorite toggles and API-backed item-detail dialogs.
- Keyboard-accessible FAQ accordion with one answer open at a time.
- Contact form with client and server validation, persistent message storage, error feedback, and reset after confirmed saving.
- Responsive layouts and reduced-motion support.

All listings, conditions, and prices are fictional samples. React manages the search, menu toggle, category, save, view, submit, and reset controls. Favorites live only in the current page and reset on navigation or refresh. The contact form sends details to `/api/contact` and the Node.js backend saves them in `.data/messages.jsonl`, outside this public folder. While submitting, the form disables its fields and button and displays a sending state. Authentication, payment, seller chat, and email delivery are not implemented.

## Edit the project

Change static page content in the HTML files and styling in `css/style.css`. React source lives in `../frontend/`: `Header.jsx` owns header buttons and search, `Catalogue.jsx` owns category buttons, product cards, favorites, and the detail dialog, and `ContactForm.jsx` owns contact submission and reset. `main.jsx` mounts these components in the existing HTML using portals. Edit these sources rather than the generated `js/app.js`.

The header markup in HTML is a fallback; edit `Header.jsx` for the active header. Category menus and footers remain repeated in all five HTML pages, so update all five when changing those shared links. Category links use `index.html?q=search-term#featured`. Edit product data in `../server/data/products.json`; it is the only source for the product cards and details. `npm run dev` watches React and backend sources; refresh the browser after changes. `npm start` builds a production bundle automatically.

Replace illustrations under `images/products/` with your own photos, and update the product JSON and any static HTML image paths. SVG artwork is original placeholder artwork created for this prototype. Frontend assets, including React, are bundled and served locally without a CDN.

## Backend files

The project root contains `server/app.js` (Express routes and static hosting), `server/index.js` (startup), `server/message-store.js` (serialized local message writes), `server/data/products.json` (sample catalogue), and `test/api.test.js` (integration tests). Run `npm test` from the project root.

The existing Finds website at https://finds-brown.vercel.app/ inspired the sage palette, second-hand fashion direction, and bold typography. This is a new implementation, not a copy of its application code.
